TilPro UI Prototype

Іске қосу:
1. TilPro_UI папкасын VS Code арқылы ашыңыз.
2. index.html файлын браузерде ашыңыз немесе Live Server пайдаланыңыз.

Бұл нұсқа — интерфейс прототипі. Сөздік бөлімінде әр тілге бірнеше демонстрациялық сөз ғана бар. Толық 200 сөздік база, нақты прогресс сақтау және аккаунтқа тіркелу кейін қосылады. Қытайша Pinyin және испанша жуық оқылу үлгілері көрсетіледі.
